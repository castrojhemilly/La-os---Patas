# La-os-Patas
O Laços e Patas é um sistema desenvolvido para organizar e incentivar a adoção dos gatos que habitam o campus de um Instituto Federal, conectando a comunidade acadêmica aos animais que precisam de um lar. Embora projetado inicialmente para o contexto escolar, a arquitetura do software foi preparada para ser expandida no futuro para ONGs e abrigos.
